# fedora-kernel-bsb

Automated SRPM builds for the [ackwell/kernel-bsb](https://copr.fedorainfracloud.org/coprs/ackwell/kernel-bsb/) copr repository.

Follows the process documented for [Building a Kernel from the Fedora dist-git](https://docs.fedoraproject.org/en-US/quick-docs/kernel-build-custom/#_building_a_kernel_from_the_fedora_dist_git), applying the requisite patches to use a Bigscreen Beyond HMD outlined on the [LVRA wiki](https://vronlinux.org/docs/hardware/bigscreen-beyond/).
